Left (you edit): name, hat, hat colour, a title you have unlocked, and your favourite team; SAVE writes it to the database. Right (the game fills in): your level with an XP bar and what the next level unlocks; seven stat tiles (calculated from your match history, so they can never disagree with it); your last matches with WIN / LOSS, score, size, length and your captures / tags / deaths, MVP marked in gold; achievements, the locked ones greyed out, each unlocking a hat or a title. RESET STATS asks first and cannot be undone.

3The database (SQLite, a single file on your computer)

PLAYERS

id UUID, made on first launch
name text
hat, hat_color numbers
title text
favourite_team 0 / 1 / any
xp number
created_at date

MATCHES

id number
played_at date
mode players per team
winner 0 red / 1 blue
red_score, blue_score
length_sec

MATCH_PLAYERS

match_id → MATCHES
player_id → PLAYERS
name, team
captures, tags, deaths
score points
was_mvp, won

ACHIEVEMENTS

player_id → PLAYERS
achievement e.g. FIRST_WIN
unlocked_at date
Match ends→ server sends final stats →Your game saves one MATCHES row + your MATCH_PLAYERS row→XP added, achievements checked→"Level up!" / "Achievement unlocked" on the results card

Wins, win rate, K/D and MVP counts are not stored separately: the Profile screen asks the database for them (for example, wins = count of MATCH_PLAYERS rows where won = 1). The file lives in your user folder (C:\Users\<you>\ThroneFall\profile.db), so reinstalling the game keeps it, and you can open it in "DB Browser for SQLite" to show the tables.
